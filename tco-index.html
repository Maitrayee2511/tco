Calling Conventions

  • Define how caller and callee communicate at machine level.
  • Specify how arguments are passed — registers or stack.
  • Define where the return value is placed.
  • Determine which registers are preserved.
  • Define stack-management responsibilities.
  • Provide a standard interface between separately compiled functions.

Call and Return Mechanism

📞 Call

  1. Caller prepares arguments.
  2. Return address is saved.
  3. Control transfers to callee.
  4. Callee establishes its execution frame.

↩️ Return

  1. Function completes execution.
  2. Return value is prepared.
  3. Callee restores required state.
  4. Control returns to saved address.

Tail Calls

A tail call occurs when a function call is the final operation performed by the calling function.

No computation remains after the called function returns.

Because the caller has no further work, its stack frame can potentially be reused.

Tail calls are especially important in functional programming and recursive algorithms.

Tail Call Optimization (TCO)

TCO is a compiler optimization that eliminates unnecessary stack-frame creation for calls in tail position.

  • Caller has no remaining computation.
  • Current activation record can be reused.
  • Tail-recursive functions can use constant stack space.
  • Useful when recursion replaces iteration.

TCO in Functional Languages

Functional languages often use recursion instead of traditional loops.

TCO prevents each recursive call from creating a new stack frame.

This allows deep recursion to use approximately constant stack space when the calls remain in tail position.

Recursion + TCO → Memory efficiency similar to iteration

Benefits & Limitations

Advantages

  • Reduces stack memory usage
  • Helps prevent stack overflow for deep tail recursion
  • Makes recursion comparable to iteration in memory efficiency

Limitations

  • Applies only to calls in tail position
  • Non-tail recursion cannot be optimized this way
  • Debugging and stack traces may be less intuitive

Important: TCO improves memory efficiency, but does not eliminate the computational cost of recursion.

Conclusion

  • Call and return mechanisms manage control transfer and execution state.
  • Activation records, call stacks and calling conventions support runtime execution.
  • A tail call occurs when the function call is the final operation.
  • TCO allows the current stack frame to be reused.
  • TCO makes suitable recursive programs memory-efficient, particularly in functional languages.
